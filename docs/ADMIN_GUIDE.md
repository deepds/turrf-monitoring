# Руководство администратора

Развёртывание, настройка и административные операции. Эксплуатация ночного
сбора — в [RUNBOOK.md](RUNBOOK.md).

---

## 1. Требования

| Что | Версия | Зачем |
|---|---|---|
| Docker + Compose v2 | 27+ | Весь стек |
| PostgreSQL | 16 | Источник истины (в составе стека) |
| Redis | 7 | Брокер Celery (в составе стека) |
| Диск | от 200 ГБ | Сырые ответы: ≈ 78 000 файлов в сутки |
| RAM | от 8 ГБ | Воркеры и база |

**Узел развёртывания обязан иметь доступ к `ticket.rzd.ru` и `mcp.tutu.ru`.**
Проверить до установки:

```bash
curl -s -o /dev/null -w '%{http_code}\n' -A 'Mozilla/5.0' \
  'https://ticket.rzd.ru/api/v1/suggests?Query=Москва&Language=ru&TransportType=rail'
```

Ответ, отличный от `200`, означает, что железная дорога будет собираться одним
источником вместо двух.

---

## 2. Установка

```bash
git clone <репозиторий> && cd turrf_monitoring
cp .env.example .env      # затем отредактировать
docker compose up -d --build
```

Миграции применяет контейнер `api` при старте. Несколько процессов,
одновременно накатывающих схему, дают гонку на `alembic_version`, поэтому
делает это только он.

## 3. Настройки

| Переменная | Умолчание | Смысл |
|---|---|---|
| `TMO_DB_PASSWORD` | `tmo_dev_pwd` | Пароль PostgreSQL. **Обязательно сменить** |
| `TMO_ADMIN_TOKEN` | пусто | Токен административных операций. Пусто = операции выключены |
| `TMO_CORS_ORIGINS` | `http://localhost:5173` | Список через запятую либо JSON-массив |
| `TMO_UI_PORT` / `TMO_API_PORT` | `8090` / `8091` | Внешние порты |
| `TMO_PG_PORT` / `TMO_REDIS_PORT` | `55432` / `56379` | Внешние порты хранилищ |
| `TMO_WORKER_CONCURRENCY` | `8` | Потоков в пуле сбора |
| `TMO_TUTU_CONCURRENCY` | `8` | Одновременных обращений к Туту |
| `TMO_RZD_CONCURRENCY` | `4` | Одновременных обращений к РЖД |
| `TMO_LOG_LEVEL` / `TMO_LOG_FORMAT` | `INFO` / `json` | Логи |
| `TMO_PIP_INDEX_URL` | публичный PyPI | Индекс пакетов при сборке образа |

**Пустой `TMO_ADMIN_TOKEN` означает «выключено», а не «открыто всем».**
Административные эндпоинты отвечают `403`, пока токен не задан.

### Если `pypi.org` недоступен из сети развёртывания

Проверено на узле кластера: индекс `pypi.org` закрыт, файловый хост
`files.pythonhosted.org` открыт. Задать зеркало:

```bash
TMO_PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple
TMO_PIP_TRUSTED_HOST=mirrors.aliyun.com
```

Зеркало — свойство сети развёртывания, поэтому в образ оно не зашивается.

## 4. Запуск рядом с первой версией

Порты выбраны так, чтобы стек работал рядом с v1 на том же узле: её
исторические raw-ответы и Offers — evidence, а не мусор. Проверить занятость
перед запуском:

```bash
ss -lnt | grep -E ':(8090|8091|55432|56379)\b'
```

---

## 5. Первый запуск

```bash
# 1. Проверить источники
docker compose exec api python -m tmo.cli check-sources

# 2. Убедиться, что методика и Golden Dataset в порядке
docker compose exec api python -m tmo.cli golden

# 3. Демонстрационный снимок без сети — проверка конвейера целиком
docker compose exec api python -m tmo.cli demo-snapshot --horizon 5

# 4. Боевой сбор
docker compose exec api python -m tmo.cli collect --snapshot-date today
```

Демонстрационный снимок помечается `is_synthetic` и **никогда** не становится
витриной рынка: на экране он показан красной полосой, а
«последним опубликованным» не выбирается.

## 6. Административные операции

Обе меняют состояние и закрыты токеном.

```bash
curl -X POST -H "X-Admin-Token: $TMO_ADMIN_TOKEN" \
  http://localhost:8091/api/v1/admin/snapshots/2026-08-07/retry

curl -X POST -H "X-Admin-Token: $TMO_ADMIN_TOKEN" \
  "http://localhost:8091/api/v1/admin/snapshots/2026-08-07/recalculate?profile_version=baseline_v1"
```

Обе ставят задачу в очередь, а не выполняют её в HTTP-запросе: обращение к
источникам внутри веб-обработчика превратило бы дашборд в клиента источников.

## 7. Изменение методики

**Активную версию менять на месте запрещено.** Хеш содержимого фиксируется при
первом применении; правка версии, на которую сослался расчёт, останавливает
прогон с ошибкой.

Порядок изменения:

1. Скопировать `tmo/catalog/data/profiles/baseline_v1.yaml` в
   `baseline_v2.yaml`, изменить нужное, поднять `version`.
2. Пересчитать исторический снимок новой версией **без активации**:
   ```bash
   docker compose exec api python -m tmo.cli recalculate \
     --snapshot-date 2026-08-07 --profile baseline_v2 --compare-only
   ```
3. Сравнить результаты двух расчётов.
4. Активировать: `TMO_ACTIVE_METHODOLOGY_PROFILE=baseline_v2`, перезапустить
   `api`, `worker`, `beat`.

Прежние расчёты остаются неизменными: на них ссылаются уже показанные цифры.

Для разработки есть `TMO_ALLOW_METHODOLOGY_REREGISTER=true`. Он **не работает**,
если на версию уже сослался расчёт.

## 8. Безопасность

| Что | Как устроено |
|---|---|
| Allowlist хостов | Коннектор физически не может обратиться к хосту вне списка источника |
| Секреты | Только через переменные окружения; в git, во фронтенд, в выгрузки и в тексты ошибок не попадают |
| Ответы об ошибках | Наружу — без подробностей: в трассировке могут быть параметры подключения |
| Административные операции | Токен в заголовке; по умолчанию выключены |
| Политика браузера | `Content-Security-Policy` запрещает странице исходящие соединения куда-либо, кроме своего происхождения |
| Процесс в контейнере | Не root |

## 9. Обновление

```bash
git pull
docker compose build
docker compose up -d
```

Миграции накатятся при старте `api`. Откат — на предыдущий тег образа; при
обратно несовместимой миграции откат схемы делается вручную и осознанно.

## 10. Резервное копирование и ретеншен

```bash
docker compose exec -T postgres pg_dump -U tmo -Fc tmo > tmo-$(date +%F).dump
docker run --rm -v tmo_raw_storage:/data -v "$PWD":/backup alpine \
  tar czf /backup/raw-$(date +%F).tar.gz -C /data .
```

Ретеншен: тела сырых ответов удаляются через 45 суток задачей `tmo.purge_raw`.
**Метаданные, Offers и метрики не удаляются никогда** — без них опубликованную
цифру нельзя объяснить.

Рост хранилища: ≈ 78 000 файлов в сутки, ≈ 0,4–5,2 млн строк `offers` в сутки.
При выходе за 30 суток истории рассмотреть партиционирование `offers` и
`metric_offer_links` по `snapshot_id`.
